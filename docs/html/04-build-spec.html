مواصفة بناء وكيل تشيك

شجرة الملفات، عقود البيانات، مسؤولية كل حزمة، ومعيار الإنجاز لكل واحدة. المبرمج ينفّذ من هنا بلا قرارات معمارية.

pnpm workspaces·TypeScript strict·Next.js 15 + Node worker
01

قاعدة بنيوية واحدة: حزمة في packages/ ممنوع أن تستورد next أو تعرف عن الطلب/الاستجابة. تأخذ بيانات وتُرجع بيانات — وبهذا تُختبر بلا شبكة ولا خادم.

02

العقود — packages/core/types.ts

هذا أهم ملف في المشروع. اكتبه أولاً وثبّته. بعده يستطيع مبرمجان أن يشتغلا بالتوازي بلا تصادم.

export type Platform = 'salla'|'zid'|'shopify'|'woocommerce'|'custom';
export type Engine   = 'chatgpt'|'ai_overviews'|'ai_mode'|'perplexity';
export type ScanKind = 'quick'|'full'|'monitor';
export type ScanStatus = 'queued'|'running'|'done'|'failed';
export type Severity = 'critical'|'high'|'medium'|'low';
export type Bilingual = { ar: string; en: string };

// ── ما نعرفه عن المتجر قبل أي سؤال
export interface StoreProfile {
  domain: string;
  platform: Platform;
  category: string;          // "عبايات نسائية"
  city: string | null;      // "الرياض"
  locale: string;            // "ar-SA"
  currency: string | null;
  productUrls: string[];    // حتى 10 — من sitemap أو الروابط
}

// ── سؤال شراء بلهجة السوق
export interface BuyingQuestion {
  id: string;
  text: string;
  intent: 'discovery'|'price'|'shipping'|'comparison';
}

export interface CompetitorMention {
  name: string;
  domain: string | null;
  position: number;         // ترتيب ظهوره في النص، 1 = الأول
}

// ── ★ العقد المركزي: هذا ما يبيعه المنتج
export interface EngineAnswer {
  questionId: string;
  engine: Engine;
  answerText: string;        // حرفياً كما خرج — ممنوع أي تعديل
  citedUrls: string[];
  storeMentioned: boolean;
  competitors: CompetitorMention[];
  capturedAt: string;
  costMicros: number;         // دولار × 1e6 — للمحاسبة
}

export interface SecurityFinding {
  kind: 'domain_expiry'|'tls_expiry'|'no_dmarc'|'exposed_secret'
      | 'dangling_cname'|'missing_headers'|'cookie_flags'|'mixed_content';
  severity: Severity;
  title: Bilingual;
  detail: Bilingual;
  evidence: string;          // ★ مطموس دائماً — انظر القسم 08
  expiresAt?: string;
}

export interface RuleResult {
  key: string;                // "schema.product" لا رقم
  passed: boolean;
  weight: number;
  detail: Bilingual;
  evidence: string;
  fixSnippet?: string;        // كود جاهز للصق
}

// ── ما ترجعه ‎GET /api/scan/:id
export interface ScanResult {
  id: string;
  kind: ScanKind;
  status: ScanStatus;
  profile: StoreProfile | null;
  questions: BuyingQuestion[];
  answers: EngineAnswer[];
  security: SecurityFinding[];
  rules: RuleResult[];
  shareOfVoice: { store: number; top: CompetitorMention | null; total: number };
  error?: string;
}
معيار الإنجاز: الملف يمرّ tsc --noEmit بـstrict: true، ولا يستورد أي حزمة خارجية.
03

الحزم — المسؤولية والتوقيع

packages/fetcherالجلب السلبي الآمن — كل شبكة تمرّ من هنا
export async function safeFetch(url: string, opts?: {
  timeoutMs?: number;    // افتراضي 10000
  maxBytes?: number;     // افتراضي 2_000_000
  method?: 'GET'|'HEAD';
}): Promise<{ status: number; headers: Record<string,string>;
              body: string; ttfbMs: number; finalUrl: string }>;

يحلّ الـDNS أولاً ويرفض: 127.0.0.0/8 · 10./172.16./192.168. · 169.254.0.0/16 · ::1 · fc00::/7. يعيد التحقق بعد كل إعادة توجيه (حد 3).

معيار الإنجاز: اختبار يثبت رفض http://169.254.169.254/ وإعادة توجيه تنتهي إلى IP داخلي.
packages/llmتجريد المزوّد — ox-alpha مع احتياطي
export interface LlmProvider {
  name: string;
  complete(p: { system: string; user: string; json?: boolean })
    : Promise<{ text: string; costMicros: number }>;
}
// index.ts — المحاولة بالترتيب، السقوط عند أي خطأ
export const llm = withFallback([ oxAlpha, deepSeekFlash ]);

إلزامي لا يستدعي أي ملف آخر oxAlpha مباشرةً — فقط llm.complete(). ox-alpha معاينة مجانية لفترة محدودة؛ يوم تختفي يتغيّر سطر واحد فقط.

التعليمات الثابتة أولاً في البرومبت، ومحتوى المتجر آخراً — الكاش يعمل على البادئة فقط.

معيار الإنجاز: اختبار يُسقط المزوّد الأول عمداً ويتحقق أن الثاني ردّ ونتيجة costMicros صحيحة.
packages/visibilityالمرآة — قلب المنتج
profile.ts    buildProfile(html, domain, robots) → StoreProfile
questions.ts  generateQuestions(profile, n) → BuyingQuestion[]
ask.ts        askEngine(engine, question, locale) → { text, urls, costMicros }
extract.ts    extractMentions(answerText, profile) → {
                 storeMentioned: boolean;
                 competitors: CompetitorMention[];
              }

extractMentions يطابق: اسم النطاق، واسم المتجر بالعربية، والاسم بلا «متجر/محل». المنافس = أي اسم تجاري في النص ليس هو المتجر. ممنوع تعديل answerText إطلاقاً — يُخزَّن حرفياً.

معيار الإنجاز: 10 إجابات ثابتة محفوظة كـfixtures، والاستخراج يطابق المتوقّع في العشرة.
packages/readinessالقواعد الـ64 — بعد الإصلاح

كل قاعدة ملف مستقل يُصدّر { key, weight, evaluate(ctx): RuleResult }. أربعة إصلاحات إلزامية:

الإصلاحماذا يتغيّر
robotsاستخدم robots-parser وحلّل كتلة كل User-agent. المنطق الحالي مقلوب: يُنجح متجراً يحظر الجميع ويُرسب متجراً يسمح لـGPTBot.
صفحات المنتجقواعد Product/Offer/Rating تُقيَّم على profile.productUrls، لا على الرئيسية.
الأوزانالنتيجة = Σ(weight × passed) / Σweight — لا عدّ القواعد.
PageSpeedاحذف المعادلة المخترعة. إمّا pagespeed.ts الحقيقي، أو لا يُعرض رقم إطلاقاً.
معيار الإنجاز: لكل قاعدة اختباران على HTML ثابت — حالة ناجحة وحالة راسبة — والاثنان يمرّان.
packages/securityفحص سلبي فقط
whois.ts    domainExpiry(domain) → { expiresAt, daysLeft }
tls.ts      certInfo(domain)    → { expiresAt, daysLeft, protocol }
dns.ts      mailAuth(domain)    → { spf, dkim, dmarc: boolean }
            danglingCnames(domain) → string[]
headers.ts  headerAudit(headers) → SecurityFinding[]
secrets.ts  scanJsForSecrets(jsUrls) → SecurityFinding[]

قانوني لا مسح منافذ، لا تخمين مجلدات، لا حقن. كل ما هنا يفعله متصفح عادي عند زيارة الموقع. الدرجة 2 (المفاتيح المكشوفة) خلف ملكية مُثبتة فقط.

معيار الإنجاز: اختبار يثبت أن evidence لا يحتوي مفتاحاً كاملاً في أي مسار.
packages/dbDrizzle + Postgres
createScan(input) → scanId
updateScanStatus(id, status, error?)
saveProfile / saveAnswers / saveSecurity / saveRules
getScanResult(id) → ScanResult
cacheGet(domain) / cacheSet(domain, scanId, ttl=24h)
معيار الإنجاز: الترحيلات تعمل من صفر، وgetScanResult يُرجع النوع كاملاً باستعلام واحد.
04

قاعدة البيانات

create table stores (
  id uuid primary key default gen_random_uuid(),
  domain text unique not null,
  platform text,
  verified_at timestamptz,          -- ★ يجيز الفحص الأمني العميق
  verify_method text,                 -- salla_oauth | dns_txt | file | email
  created_at timestamptz default now()
);

create table scans (
  id uuid primary key default gen_random_uuid(),
  store_id uuid references stores(id),
  kind text not null,                 -- quick | full | monitor
  status text not null default 'queued',
  profile jsonb,
  share_of_voice jsonb,
  cost_micros bigint default 0,
  ip_hash text,                       -- sha256(ip+salt) — لحدّ المعدّل
  error text,
  started_at timestamptz, finished_at timestamptz,
  created_at timestamptz default now()
);

create table questions (
  id uuid primary key default gen_random_uuid(),
  scan_id uuid references scans(id) on delete cascade,
  text_ar text not null, intent text, locale text
);

create table engine_answers (       -- ★ هنا يعيش المنتج
  id uuid primary key default gen_random_uuid(),
  scan_id uuid references scans(id) on delete cascade,
  question_id uuid references questions(id) on delete cascade,
  engine text not null,
  answer_text text not null,          -- حرفياً، بلا تعديل
  cited_urls text[],
  store_mentioned boolean not null,
  competitors jsonb not null,
  cost_micros bigint default 0,
  captured_at timestamptz default now()
);

create table security_findings (
  id uuid primary key default gen_random_uuid(),
  scan_id uuid references scans(id) on delete cascade,
  kind text not null, severity text not null,
  title jsonb, detail jsonb,
  evidence_redacted text not null,  -- ★ لا يُخزَّن سرّ كامل أبداً
  expires_at timestamptz
);

create table rule_results (
  scan_id uuid references scans(id) on delete cascade,
  key text not null, passed boolean, weight int,
  detail jsonb, evidence text, fix_snippet text,
  primary key (scan_id, key)
);

create table leads (
  id uuid primary key default gen_random_uuid(),
  email text not null, scan_id uuid references scans(id),
  locale text, created_at timestamptz default now()
);

create index on scans(created_at desc);
create index on scans(ip_hash, created_at desc);
create index on engine_answers(scan_id);

08

قواعد ملزمة — لا تُناقَش

01الطمس عند المصدر. redact() في core يُستدعى قبل أي إرجاع أو تخزين. سرّ كامل لا يدخل الذاكرة الدائمة ولا السجلّات. sk_live_••••4f2a فقط.
02لا شبكة خارج safeFetch. أي fetch() مباشر في packages/ يُرفض في المراجعة. هذا ما يمنع SSRF.
03لا استدعاء مباشر لـ ox-alpha. فقط llm.complete(). المزوّد المجاني مؤقّت بطبيعته.
04الكاش وحدّ الـIP قبل الترويج. بلاهما حملة أفلييت واحدة تحرق آلاف الريالات في شهر.
05answerText حرفي. لا تنظيف، لا اقتصاص، لا إعادة صياغة. هو الدليل — وتعديله يُبطل المنتج.
06لا رقم بلا مصدر. إن لم يأتِ الرقم من قياس فعلي، لا يُعرض. هذا يشمل PageSpeed.
07الفحص الأمني العميق خلف verified_at. بلا ملكية مُثبتة: الطبقة السلبية فقط.
08strict: true ولا any. أربعة من الأخطاء السبعة الحرجة كان المترجم سيرفضها.
