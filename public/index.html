⚡ مولد ملفات الذكاء الاصطناعي والحماية التلقائي

انسخ الأكواد التالية وضعها في مجلد متجرك الرئيسي لرفع نتيجة الجاهزية وحماية متجرك من الطلبيات الوهمية فوراً:

1. ملف `llms.txt` لإرشاد نماذج الـ AI:

# llms.txt generated by AITChek.online

2. سياسة الأمان `agent.json` (تقييد الدفع عند الاستلام وحظر البوتات المزيفة):

{ "agent_spec_version": "1.0", "security_policy": { "cash_on_delivery_allowed": false, "require_3d_secure_otp": true } }

3. تصريحات `robots.txt` لبوتات الـ AI المعتمدة:

User-agent: GPTBot Allow: /

4. كود Schema.org JSON-LD للمنتجات:

<script type="application/ld+json"> { "@context": "https://schema.org/", "@type": "Product", "name": "اسم المنتج", "offers": { "@type": "Offer", "priceCurrency": "SAR", "price": "199.00" } } </script>
