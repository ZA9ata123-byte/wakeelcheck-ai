# جسر وكيل تشيك

وسيلة تنسيق بين **الرئيس** و**claude** و**codex** — كي يقرأ كل واحد حالة
الفريق ورسائل الآخرين عند بدء جلسته، بلا أن ينقلها الرئيس بيده.

خاص بهذا المشروع وحده. لا علاقة له بأي جسر آخر على هذا الجهاز.

---

## القاعدة الوحيدة

```
🔴 اقرأ الكل · واكتب في صندوقك وحدك
```

| الملف | من يكتب |
|---|---|
| `outbox/raees.md` | الرئيس وحده |
| `outbox/claude.md` | claude وحده |
| `outbox/codex.md` | codex وحده |
| `BOARD.md` | claude — والتصحيح يُطلب في صندوقك، لا يُكتب مباشرة |
| `PROTOCOL.md` | الرئيس |

**كاتب واحد لكل ملف = صفر تصادم.** لا أقفال ولا دمج يدوي ولا رسالة ضائعة.

---

## الأوامر

```bash
team/bin/bridge read claude              # ماذا يُنتظر منّي
team/bin/bridge send claude codex "عنوان" <<'EOF'
النص هنا
EOF
team/bin/bridge close claude CLAUDE-004  # أنهيتُ رسالتي
team/bin/bridge ask claude "سؤال"        # يرفع للرئيس ويوقف
team/bin/bridge board                    # من يعمل على ماذا
team/bin/bridge log                      # آخر الأحداث
```

**تغلق رسائلك أنت فقط** — لا تغلق ما كتبه غيرك. السكربت يمنعها.

## قانون الجلسة

### قبل أن تكتب سطراً

```
① team/bin/bridge read <اسمك>   رسائل مفتوحة إليك
② team/bin/bridge board          الحالة الآن · ومن يملك ماذا · وما هو مجمّد
③ CLAUDE.md                      القواعد الثمانية — تُطاع أوّلاً
```

### أثناء العمل

```
🔴 لا تلمس ما يملكه غيرك في BOARD.md — ولو رأيته خطأً
🔴 واكتشافٌ في نطاق غيرك: صِفه في صندوقك ولا تُصلحه بصمت
🔴 والمجمّد لا يُلمس حتى يُرفع تجميده صراحة
```

### عند الانتهاء

```
④ سلّم النتيجة في صندوقك — بالأمر الذي يُثبتها لا بالادّعاء
⑤ أغلق رسائلك المنجزة
```

---

## ما ليس هو

```
⛔ ليس تفويضاً بـpush أو merge أو deploy
⛔ ولا يُلغي CI ولا المراجعة
⛔ ولا هو بديل عن git
```

**والقرار الذي يغيّر الإصدار ينتقل في النهاية إلى المستودع.**

## ممنوعات مطلقة

```
⛔ مفاتيح API · كلمات مرور · tokens
⛔ بيانات عملاء — أسماء أو بريد أو هواتف
⛔ لوغات خام
```

**وإن احتجت الإشارة إلى سرّ: اذكر اسم المتغيّر لا قيمته.**
هذه هي القاعدة 01 في `CLAUDE.md`، وتنطبق هنا كما تنطبق في الكود.

الصلاحيات: المجلدات `0700` · الملفات `0600`.

## من يملك ماذا

| | النطاق |
|---|---|
| **الرئيس** | القرار · المفاتيح · المراجعة البشرية · التجربة على الموقع الحيّ |
| **claude** | `packages/` — القواعد والمحرّكات وخطّ الأنابيب · الوثائق |
| **codex** | البنية والتشغيل — Redis · Turnstile · قاعدة البيانات · Sentry · النشر |

**ملفات مختلفة، فلا تصادم.** ومن احتاج أن يلمس نطاق غيره: يطلبه في صندوقه.

---

## الإيقاظ — العقد الصادق

```
① claude يُوقَظ آلياً:   team/bin/bridge wake claude   ← يعمل فعلاً
② codex لا يُوقَظ آلياً:  لا CLI له على هذا الجهاز
③ جلسة مغلقة لا تُوقَظ نفسها — الاستدعاء البشري القصير يبقى لازماً
```

**فالجسر حيٌّ في التوصيل، ولا يدّعي أكثر.** ومن قال لك إنه يوقظ كل شيء
تلقائياً فقد وصف ما يتمنّاه لا ما يعمل.

## متى تتوقف وتنادي الرئيس

```
bridge ask <اسمك> "السؤال"
```

- قرار يغيّر المنتج أو السعر أو النطاق
- push أو merge أو deploy
- تعارض بينك وبين الآخر لم يُحسم برسالتين
- شكّ في مفتاح أو بيانات عميل

**وما دون ذلك: قرّروه بينكم ولا توقفوا العمل.**
