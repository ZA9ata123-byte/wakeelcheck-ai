# نموذج التقرير

ما يراه التاجر — مولَّداً من خطّ الأنابيب الحقيقي.

```bash
pnpm run specimen      # يولّد report.json ثم report.html
pnpm run build:docs    # يضيف report.pdf
```

| الملف | ما هو |
|---|---|
| `report.json` | مخرَج `runScan` كما هو. عقد الـAPI نفسه الذي يعيده `GET /api/scan/:id` |
| `report.html` | الصفحة المرسومة برموز نظام العلامة |
| `report.pdf` | نسخة للمشاركة مع من لا يفتح المستودع |

---

## ما هو حقيقي وما ليس كذلك

**المدخل ثابت.** متجر مُختلق (`nourabaya.sa`) بـHTML وrobots.txt وشهادة ونطاق
مكتوبة في `scripts/make-specimen.ts`. لا شبكة، لا مفاتيح.

**المخرَج محسوب.** القواعد العشرون والشدّات الأمنية وحصة الصوت والنتيجة
الموزونة — كلها من `runScan`، بنفس الكود الذي سيعمل في الإنتاج. لم يُكتب رقم
واحد منها يدوياً.

**نصوص إجابات المحرّكات ثابتة.** هذه وحدها تحتاج مفتاحاً، والوثيقة تعلّمها
كذلك في أعلى الصفحة حتى لا تُقرأ كقياس. القاعدة 06.

---

## ماذا يُثبت هذا النموذج

مقصود أن يُخفق المتجر في أشياء بعينها، لأن كل إخفاق يُثبت إصلاحاً:

| ما يظهر | ما يُثبته |
|---|---|
| `robots.gptbot` **راسب** | المحلّل يقرأ المجموعات لا `includes()` — المتجر يحظر GPTBot صراحةً |
| `consistency.price` **راسب** | ‏299 في JSON-LD مقابل 349 في الوسم — التناقض يُمسَك |
| `exposed_secret` **حرج** | مفتاح في ملف JS عام. الدليل مطموس: `sk_live••••••••••••WxYz` |
| `pk_live_` **لا يُبلَّغ عنه** | مفتاح علني لا سرّي — الطمس لا يُنتج إنذاراً كاذباً |
| «متجر الشرق» **غير موجود** | النموذج اقترحه والصمام أسقطه: لا يظهر في نص أي إجابة |
| حصة الصوت `0 / 8` | المتجر غائب عن كل إجابة — وهذا هو المنتج |

آخر سطرين هما الأهم: العلامة لا تُوضع إلا على اسم تحقّق البرنامج من وروده
حرفياً، والتقرير لا يحمل قيمة سرّ كاملة في أي حال.

---

## لمن

- **المصمم** — `report.html` هو الشاشة التي يصمّم عليها. كل قسم بحالته الحقيقية.
- **المبرمج** — `report.json` هو شكل الاستجابة. ابنِ عليه بدل اختراع بيانات وهمية.

لتغيير المتجر النموذجي، عدّل الثوابت في `scripts/make-specimen.ts` وأعد التوليد.
السكربت داخل `pnpm typecheck`، فأي انحراف عن العقود يُمسَك قبل التشغيل.
